## Лабораторная работа №2
**Тема:** Бинарная классификация (Титаник)

**Что сделано:**
- Проведена предобработка данных: заполнены пропуски в возрасте (медианой), удалены малополезные признаки (`Cabin`, `Ticket`), из имени извлечены титулы пассажиров.
- Категориальные признаки (`Sex`, `Title`) закодированы с помощью LabelEncoder, признак `Embarked` преобразован методом One-Hot Encoding.
- Обучены три модели классификации: логистическая регрессия, случайный лес и градиентный бустинг. Оценено их качество по метрикам Accuracy, Precision, Recall, F1-score, ROC-AUC.
- **Результат:** Лучшей моделью оказался градиентный бустинг (F1 = 0.774, ROC-AUC = 0.830). Проведен анализ влияния порога классификации на метрики Precision и Recall.
